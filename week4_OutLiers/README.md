# Experiment 04: Linear Regression and Residual Analysis

## Aim
To implement a simple linear regression model, determine the best-fit line between a predictor and target variable, analyze residuals to evaluate linear regression assumptions, and study the effect of outliers on the regression model.

## Objectives
- Understand the basic concept of Linear Regression.
- Fit a simple linear regression model using a single predictor.
- Determine the slope and intercept of the regression line.
- Visualize the fitted regression line along with the observed data.
- Calculate and analyze residuals.
- Construct residual plots against fitted values.
- Understand the assumptions of linear regression, including linearity and homoscedasticity.
- Investigate the sensitivity of linear regression to extreme outliers.

## Contents
- **`Experiment_04.ipynb`**: The Jupyter Notebook containing the full implementation of the experiment. It walks through data loading, model fitting, residual analysis, and testing the effects of outliers.

## Tools & Libraries Required
- Python 3.x
- Jupyter Notebook
- Libraries: `NumPy`, `Matplotlib`, `Scikit-learn`
